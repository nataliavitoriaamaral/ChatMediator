# Projeto: ChatMediator

Sistema de chat em **Java**, focado na implementação do Padrão de Projeto **Mediator**.

## Sobre o Projeto
O objetivo é garantir que os usuários (`UsuarioConcreto`) se comuniquem através de um canal central (`ChatMediator`), evitando que eles tenham dependência direta (acoplamento) uns com os outros.
